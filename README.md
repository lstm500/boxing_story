# RING SENSE

スマホの向きで相手を追い、画面のパンチ／防御ボタンで戦うボクシングゲームです。

## すぐ遊ぶ

[公開サイト版を開く](https://ring-sense.ayumu-harada-8593.chatgpt.site/)。スマホではHTTPSのページを端末のブラウザーで開き、向きセンサーの利用を許可してください。音は画面上部でON/OFFを切り替えられます。

## Streamlit版を起動する

`app.py`と`requirements.txt`を同じフォルダーに置き、Pythonをインストールしたパソコンのターミナルで次を実行します。

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

表示されたローカルURLをブラウザーで開いてください。スマホからアクセスする場合は、スマホと実行中のパソコンが接続できるネットワークが必要です。`app.py`にはゲーム画面とJavaScriptが圧縮して内蔵されており、観客の歓声も内蔵されており、追加の画像・動画・音声ファイルは不要です。

**スマホ操作の制約:** Streamlit版はゲームを埋め込み画面で動かします。ブラウザーや公開先の権限設定によって向きセンサーが使えないことがあります。その場合、試合は開始できません。スマホでの試合は公開サイト版を利用してください。練習メニューは向きセンサーなしで利用できます。

リングの高さは端末の表示領域から上部メニューと下部操作欄を差し引いて自動調整します。小さい画面でも防御・移動・ダッキング・一時停止を表示し、長い説明文はスクロールして読めます。Streamlit版では埋め込み枠も親画面の見えている高さに合わせて調整します。

## 操作

| 操作 | 動作 |
| --- | --- |
| 端末の向きを左右に変える | 相手を視界に捉える |
| パンチ中、光る防御位置をタップ | ブロック／パーリング |
| 攻撃できるときにパンチ位置をタップ | 対応するパンチを打つ |
| 金色に変わったパンチ位置をタップ | 威力の高いカウンター |
| 左移動／右移動 | 位置を変え、攻撃の角度を作る |
| ダッキング | 基本的にアッパー以外を回避。ダッキング中の移動はウィービング |
| 必殺技（ストーリーで装備後） | 4～6連打。技ごとに待機時間と効果が異なります |

ジャブは素早く打てますが、連打するとスタミナ消費が増えます。ボディ・フック・アッパーの基本消費は従来の半分（7・8.5・12.5）です。威力はそれぞれ9・12・18に調整し、ダメージと消費の比率はジャブが最も高くなる設定です。相手もガード、カウンター、ダッキング、ウィービングを使い、上体を大きく沈めて横へ傾けます。日本タイトル戦以降は、こちらが攻撃していない時間にも回避動作を始めます。回避動作中の相手には、アッパー以外のパンチは空振りです。コンビネーション名は命中に関係なく打った順番で表示され、重なる名称も表示されます。歓声は命中時だけ流れます。相手は通常オーソドックスで、約18%の試合ではサウスポーです。前手・前足とパンチの左右が構えに合わせて変わり、ステータスには「右構え」「左構え」が表示されます。ストーリーが進むほどダッキング・ウィービングの確率が上がり、パーリングは内側へ払う、ブロックは頭またはボディを覆う動作になります。自分がダッキング・ウィービング・横移動中は相手の次の攻撃準備が20%遅くなり、なお当たるパンチのダメージが12%下がります。行動を終えると戻ります。

## モードと進行

- **練習:** コンビネーションとディフェンスの手順を選び、成功後は自動でもう一度始まります。
- **フリー対戦:** 難易度と試合時間を選びます。
- **ストーリー:** 4・6・8回戦、タイトル戦、世界戦へ進みます。1ラウンド15秒で、それぞれ4・6・8・10・12ラウンド制です。世界王座獲得後は5回の防衛で全クリアです。世界戦では同じ難易度の同じ選手と重複して当たらず、対戦済み選手の記録は新しい選手で最初から始めると消えます。世界戦と防衛戦の前には、その試合の相手名を「VS ○○」で表示し、開始ボタンを押すまで時計は進みません。
- ストーリーを開くと「続きから」「新しい選手で最初から」と開放済みの試合を選べます。「新しい選手で最初から」または試合画面の「進行を最初から」で、その難易度の選手・成長・進行を作り直し、選手選択へ戻ります。選んだ選手には3種類の初期能力がランダムに付きます。
- 勝利ごとに成長ポイントをランダムで1～3点獲得します。ラウンド間はリング操作を覆う全画面パネルで裏向きの5枚から1枚選びます。選ぶ前に一度だけ5枚すべてを引き直せます。選んだ後も一度だけ、そのカードを未配布のランダムな1枚と交換できます。即時回復の効果は交換時に取り消して付け替えます。カード選択後は次ラウンドの表示と二打のゴングを挟み、音の演出中は試合の時計とパンチ操作を止めます。4回戦の試合終了後（勝敗に関係なく）から必殺技を設定できます。全50種類から試合ごとに未所持の技をランダムで2種類獲得し、所持上限は8種類です。所持技から1種類を装備し、次の試合で専用ボタンから4～6連打を発動できます。技ごとにスタミナ消費・効果・待機時間が異なり、必殺技を打っている間は相手のパンチを受けません。連打中にダッキング・ウィービングでかわされたパンチは、打った側のそのパンチ分のスタミナ消費が2倍になります。試合後は成長ポイントを振り分けた後でも必殺技設定画面を経由して次戦へ進みます。世界戦の相手には実在の男子世界王者を元にした架空名を用い、元選手の防衛回数を基準にし、ゲーム内の防衛戦の進行に応じて能力が上がります。村田諒太・井上尚弥を元にした選手はゲーム内の強さを同じに設定しています。まれに見た目と能力が異なる強敵が現れます。元にした男子選手の全一覧は `boxing_world_champions_men.md` に記載しています。
- 成長ポイント1点につき、最大体力は+8、最大スタミナは+18です。威力は+4％、待機中のスタミナ回復は+10％、相手のガード率低下は4％のままです。

ストーリーの進行、選手、成長、防衛回数はブラウザーのローカルストレージに難易度別で保存されます。別のブラウザー・端末には引き継がれず、ブラウザーのサイトデータを消すと失われます。公開サイト版とStreamlit版も保存先が別です。

## 構成と確認

| ファイル | 用途 |
| --- | --- |
| `app.py` | Streamlit用の単一ファイル版 |
| `requirements.txt` | Pythonの依存関係 |
| `README.md` | この説明書 |

公開サイト版の元コードは`dist/index.html`にあります。相手選手はリングセンス独自のスポーツゲーム調イラストとして描き直し、参考のオーソドックス姿勢を基に、曲線の輪郭とセル調の陰影を持つ上半身の筋肉の陰影、紺のトランクス、肌の見える肩と前腕、短髪、前後に開いた足、斜めを向いた肩・腰、顔の前に置く両グローブへ描き直しています。肩・肘の丸いパーツを廃止し、上腕→胴体→顔→前腕・グローブの順で重ね、肩から前腕をつなげて、会場照明・観客席・コーナーポスト・ロープ・キャンバスを備えたリング背景にしています。防御位置は黄、反撃可能なパンチは紫の縁取り、練習位置は青で示します。練習の目印は試合開始時に消えます。ラウンド開始のゴングは低音の連打から短い高い金属音に変更しました。構え、ガード、パンチ、ダッキング、ウィービングには同じ部位を使い、予備動作からパンチの伸長・引き戻しへ速度が急変しない補間を使います。パンチ軌道と動作は[England Boxingの指導資料](https://www.englandboxing.org/coaching-resources/)を参考にゲーム用に簡略化しています。実在選手の映像は使用していません。

開発時の確認は`node ring-sense-check.js`で130項目実施済みです。Streamlit版はPython構文と内蔵HTMLの一致を確認済みですが、端末別の向きセンサー動作は未確認です。

## 音声素材

攻撃時の歓声は相手への命中時だけ鳴ります。単発は小さく、2発目以降のコンビネーション命中では大きく鳴ります。防御成功時は別の控えめな観客音が鳴り、連続攻撃を防ぎ切ると少し長くなります。移動だけでは鳴りません。実際の短い歓声と約500人規模の拍手の録音を編集して内蔵し、低く伸びる声の素材は使用していません。合成した発振音の歓声は使用していません。元の音声はいずれもパブリックドメインです。

- [Applause ii.ogg（thore）](https://commons.wikimedia.org/wiki/File:Applause_ii.ogg)
- [Clapping hurray (cropped).oga（starlite）](https://commons.wikimedia.org/wiki/File:Clapping_hurray_(cropped).oga)

パンチの接触音はゲーム内で生成しています。歓声の音量は端末のメディア音量にも依存します。


## v43：回復・運・カードと操作案内

モードに入る前に、スマホを左右に向けて相手を追う操作を短く案内します。試合開始前は高い金属音のゴングを鳴らし、時計と操作を一時停止します。

- 攻撃していない時間だけ、体力が基本毎秒0.65回復します。防御中・移動中でも自分がパンチを打っていなければ回復します。攻撃モーションと入力待ちのパンチがなくなり、最後の入力から0.3秒経つまで回復しません。ラウンド間・一時停止中は自動回復しません。
- 選手の「運」は成長で最大Lv.10。初期能力のランダム上昇にも含まれます。運が上がるほど回復カードとレアカードの抽選重みが増え、効果も少しずつ強くなります。最大で回復量+35％、倍率の増減幅+25％です。全レアカードに少なくとも12の体力回復を追加しました。効果の数値は選んだカードに表示されます。
- お助けカード限定の「必殺デンプシーロール」は次ラウンドだけ使用可能。左右フックを交互に高速で10〜20発打ちます。スタミナ24消費、待機時間30秒、1ラウンド1回限りです。通常の50種類の獲得・装備対象には含みません。発動中は無敵、終了・KO・次ラウンドで技の状態を解除します。
- クリティカルは通常ダメージの1.1倍。自分と相手の両方に適用します。
- イージーの間隔を広げ、全体も少し遅くしました。左右移動後1.15秒は相手の次の攻撃開始を抑えます。すでに飛んできているパンチは動作中に防御・回避してください。移動を繰り返して永久に相手の攻撃を止めることはできません。
- 最後の世界王座防衛戦は、登場する世界王者の強さの中央値より上から選びます。強い世界王者はVS画面に青→紫→金→赤のオーラを表示し、赤が最強クラスです。戦闘中は動いたときの薄い残像だけ表示します。
- 練習は1発8種類、2発24種類、3発30種類、4発20種類の計82種類。逆ワンツー、上下の打ち分け、フック・アッパーの組み合わせを含み、5発以上の練習は削除しました。
- リングは青い床、上から赤・白・青・白の4本のロープ。床の格子やサイバーな線を廃止しました。

## 開発用：相手のマスクパラメーター上限

以下は画面に直接表示しない内部上限です。個別の上限をすべて同時に使う敵ではなく、難易度・ステージ・選手・防衛回数に応じて組み合わせます。速度は基準に対する倍率、確率は対象イベントごとの判定です。

| パラメーター | 上限 |
| --- | --- |
| パンチ力 | 1.65倍 |
| パンチスピード | 1.25倍 |
| クリティカル率 | 18％ |
| 移動率 | 65％ |
| コンビネーション率 | 72％ |
| コンビネーション速度 | 1.22倍 |
| カウンター率 | 26％ |
| スタミナ | 140 |
| 体力 | 520 |
| 体力回復率 | 毎秒0.45（非攻撃中） |
| 必殺技発動率 | 22％ |
| 自分の左右移動後の攻撃発生率 | 42％（攻撃開始判定） |
| 正面の単発への平均防御・回避率 | 82％ |
| その他のパンチへの平均防御・回避率 | 58％ |

回避率の上限はブロック・パーリングと反応による回避の合算です。すでに始まっているダッキング・ウィービング中はアッパー以外をかわす既存のルールが優先されます。自分の成長上限は体力260、スタミナ320、基本パンチ力1.8倍、クリティカル20％。基本HP回復は毎秒1.2まで、カードを含む毎秒回復は7までです。
