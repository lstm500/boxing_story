# RING SENSE

スマホの向きで相手を追い、画面のパンチ／防御ボタンで戦うボクシングゲームです。

## すぐ遊ぶ

[公開サイト版を開く](https://ring-sense.ayumu-harada-8593.chatgpt.site/)。スマホではHTTPSのページを端末のブラウザーで開き、向きセンサーの利用を許可してください。音は画面上部でON/OFFを切り替えられます。

## Streamlit版を起動する

`app.py`と`requirements.txt`を同じフォルダーに置き、Pythonをインストールしたパソコンのターミナルで次を実行します。

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

表示されたローカルURLをブラウザーで開いてください。スマホからアクセスする場合は、スマホと実行中のパソコンが接続できるネットワークが必要です。`app.py`にはゲーム画面とJavaScriptが圧縮して内蔵されており、追加の画像・動画ファイルは不要です。

**スマホ操作の制約:** Streamlit版はゲームを埋め込み画面で動かします。ブラウザーや公開先の権限設定によって向きセンサーが使えないことがあります。その場合、試合は開始できません。スマホでの試合は公開サイト版を利用してください。練習メニューは向きセンサーなしで利用できます。

## 操作

| 操作 | 動作 |
| --- | --- |
| 端末の向きを左右に変える | 相手を視界に捉える |
| パンチ中、光る防御位置をタップ | ブロック／パーリング |
| 攻撃できるときにパンチ位置をタップ | 対応するパンチを打つ |
| 金色に変わったパンチ位置をタップ | 威力の高いカウンター |
| 左移動／右移動 | 位置を変え、攻撃の角度を作る |
| ダッキング | 基本的にアッパー以外を回避。ダッキング中の移動はウィービング |

ジャブは素早く打てますが、連打するとスタミナ消費が増えます。相手もガード、カウンター、ダッキング、ウィービングを使います。

## モードと進行

- **練習:** コンビネーションとディフェンスの手順を選び、成功後は自動でもう一度始まります。
- **フリー対戦:** 速度と試合時間を選びます。
- **ストーリー:** 4・6・8回戦、タイトル戦、世界戦へ進みます。1ラウンド15秒で、それぞれ4・6・8・10・12ラウンド制です。世界王座獲得後は5回の防衛で全クリアです。
- ストーリーを開くと「続きから」「はじめから」と開放済みの試合を選べます。「はじめから」を選ぶだけでは保存済みの進行は消えません。進行・選手・成長を消したい場合は、試合画面の「進行を最初から」を使います。
- 勝利時の成長ポイントとラウンド間に選ぶ裏向きのカードで選手を強化できます。世界戦の相手は防衛ごとに強くなり、まれに見た目と能力が異なる強敵が現れます。

ストーリーの進行、選手、成長、防衛回数はブラウザーのローカルストレージに速度別で保存されます。別のブラウザー・端末には引き継がれず、ブラウザーのサイトデータを消すと失われます。公開サイト版とStreamlit版も保存先が別です。

## 構成と確認

| ファイル | 用途 |
| --- | --- |
| `app.py` | Streamlit用の単一ファイル版 |
| `requirements.txt` | Pythonの依存関係 |
| `README.md` | この説明書 |

公開サイト版の元コードは`dist/index.html`にあります。パンチ軌道と動作は[England Boxingの指導資料](https://www.englandboxing.org/coaching-resources/)を参考にゲーム用に簡略化しています。実在選手の映像は使用していません。

開発時の確認は`node ring-sense-check.js`で69項目実施済みです。Streamlit版はPython構文と内蔵HTMLの一致を確認済みですが、端末別の向きセンサー動作は未確認です。
